Tetapan Video Jam
Input USB tidak dikesan. Pastikan multi-effect disambung dengan kabel OTG dan menyokong USB OTG. Buat masa ini rakaman guna mikrofon telefon.
  1. Sambung telefon ke multi-effect dengan kabel USB OTG. Multi-effect mesti menyokong USB OTG (audio USB tanpa driver) untuk berfungsi dengan telefon.
  2. Tekan Kamera, kemudian pilih input bunyi USB / multi-effect di atas.
  3. Tekan Spotify, pilih lagu dan bahagian yang kau mahu, tekan main, kemudian kembali ke sini.
  4. Tekan butang merah untuk rakam. Tekan lagi untuk berhenti.
